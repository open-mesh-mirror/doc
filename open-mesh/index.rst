About open-mesh.org
===================

open-mesh.org is the development platform for a collection of tools to
build free and open mesh networks. Its main project is B.A.T.M.A.N.
(better approach to mobile ad-hoc networking), a routing protocol for
multi-hop ad-hoc mesh networks.
