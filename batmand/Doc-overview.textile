h1. B.A.T.M.A.N. daemon Documentation Overview

batmand was the first implementation of the B.A.T.M.A.N. routing protocol. It is a user space daemon which operates on layer 3 (IP layer) by altering the routing table.

bq. batmand has not been developed further for a couple of years, but is still actively used by a few projects. Most of the active developmenttoday is performed on [[batman-adv:]]

The "manpage":https://downloads.open-mesh.org/batman/manpages/batmand.8.html describes all options of batmand.
