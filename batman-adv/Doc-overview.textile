h1. B.A.T.M.A.N. Advanced Documentation Overview

{{TOC}}

B.A.T.M.A.N. advanced (often referenced as batman-adv) is an implementation of the B.A.T.M.A.N. routing protocol in form of a Linux kernel module operating on layer 2. It is configured with the tool batctl, which is described in its "manpage":https://downloads.open-mesh.org/batman/manpages/batctl.8.html
