h2. Features

* [[Gateways|DHCP gateway optimization]]
** choose the nearest internet gateway node
* [[Bridge-loop-avoidance|Bridge loop avoidance]]
** detect and avoid loops when bridging multiple nodes into the same LAN
* [[Multi-link-optimize|Multi-link optimizations]]
** optimize traffic by using multiple links
* [[Ap-isolation|AP isolation]] and [[Extended-isolation|Extended isolation]]
** prevent communication between (wifi) clients
* [[DistributedArpTable|Distributed ARP Table]]
** speed up the network by caching ARP replies in the mesh
* [[Broadcast|Broadcasts]]
** how broadcasts are forwarded in the mesh
* [[Multicast-optimizations|Multicast optimizations]]
** avoid flooding of multicast traffic
* [[Throughput_meter|Throughput meter]]
** measure the throughput between two nodes
* [[Feature-History|Feature history]]
** batman-adv versions which introduced each feature

The [[alfred:|alfred]] daemon can additionally be used to distribute local information or visualize the mesh network.
